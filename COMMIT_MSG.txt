Proxy keys: every listener has to be bound to its own outbound

The sing-box config opened a local listener per key and wrote an outbound per
key, but nothing said which listener belongs to which outbound. sing-box sends
whatever arrives on an unbound listener out through the first outbound in the
list, so every key was dialled through the first one and the rest were never
used at all.

That is why the whole proxy fleet looked dead while the keys were alive: one
address that stopped answering made every carrier fail, the probe reported the
first key's state for all of them, and a key that could have reached the
provider was never given a chance. The config now binds every listener to its
own outbound, and a request through a listener leaves through that key and
nothing else.
