A carousel that checks every candidate and keeps the ones that work

A public proxy list is thousands of links long and almost all of them are dead.
The panel kept them all, but the node materialized the first few dozen and
checked those, over and over: the same links were tested while the rest of the
list was never tried, and a key that was never tried looked exactly like one
that did not work.

The panel now hands a node a bounded list per carrier whose order changes every
five minutes, so every candidate eventually reaches the front, and the keys a
node proved to work are handed out first and stay there. The node checks each
materialized key on its own against the services its carrier has to reach, and
reports what it found; the panel keeps that, so the order it hands out is the
order of what actually works. A key nobody has tried stays unknown rather than
being written down as broken.

The panel shows the result in the key list: a key that reaches its provider, the
latency it took, or the refusal it answered with.
